# Spec: CMDB Statistics

## Overview

CMDB统计功能（程序选项1）用于从资源录入表和安全资源表中提取资源信息，生成统计汇总表格。

## Context

该功能是 Catch 工具的核心功能之一，用户输入项目目录路径后，程序自动查找Excel文件并生成资源统计表格。

## REQUIREMENTS

### CMDB-001: 用户输入处理

**描述**：系统必须提示用户输入项目目录路径，并验证路径有效性。

**验收标准**：
- [ ] 提示用户输入项目目录
- [ ] 验证目录是否存在
- [ ] 从目录路径中提取项目名称（使用正则 `\w\d{2,3}[-_](\d*\w*\p{Han}+\d*\w*)+`）
- [ ] 路径无效时提示用户重新输入

### CMDB-002: Excel初始化

**描述**：系统必须创建并初始化统计表格Excel文件。

**验收标准**：
- [ ] 创建新的Excel文件，工作表名为"Sheet1"
- [ ] 第1-6行填写项目基本信息：
  - A1: "需求人："，B1: 申请人姓名
  - A2: "需求方："，B2: 需求方名称
  - A3: "OA发文时间："，B3: OA发文日期
  - A4: "是否分批："，B4: 是否分批交付
  - A5: "主账号："，B5: 主账号
  - A6: "项目名称："，B6: 项目名称
  - A7: "新增子网信息："，B7: 子网信息
- [ ] 第8行填写表头："云池", "节点", "可用区", "资源大类", "资源小类", "规格", "单位", "资源统计", "卷/桶数量", "备注"
- [ ] 优先使用PDF提取的信息，提取失败时使用用户手动输入的信息

### CMDB-003: PDF信息自动提取

**描述**：系统必须在Excel初始化前尝试从PDF中提取项目信息。

**验收标准**：
- [ ] 调用 `pdf_extractor.ExtractFromPDF(root)` 尝试提取信息
- [ ] 提取成功时，使用提取的信息作为默认值
- [ ] 提取失败时，记录 `Warn` 日志并回退到手动输入
- [ ] 无论提取是否成功，都允许用户确认或修改信息

### CMDB-004: 资源录入表处理

**描述**：系统必须处理资源录入表并生成统计信息。

**验收标准**：
- [ ] 在用户目录下查找包含"资源录入表"的目录
- [ ] 在该目录下查找文件名包含"资源录入"或"资源录入表"的Excel文件
- [ ] 从资源录入表中提取资源信息并统计数量
- [ ] 将统计结果写入生成的统计表格

### CMDB-005: 安全资源表处理

**描述**：系统必须处理安全资源表并生成统计信息。

**验收标准**：
- [ ] 在用户目录下的"订购评审纪要"目录中查找文件名包含"安全资源"或"安全"的Excel文件
- [ ] 从安全资源表中提取资源信息并统计数量
- [ ] 将统计结果写入生成的统计表格

### CMDB-006: Excel格式设置

**描述**：系统必须自动设置生成的Excel表格的格式。

**验收标准**：
- [ ] 自动设置列宽，适应内容长度（列A-J）
- [ ] 为数据区域添加边框（从"云池"行到最后一行，列A-J）
- [ ] 保存Excel文件到项目目录

### CMDB-007: 临时文件清理

**描述**：系统必须正确处理临时文件的创建和清理。

**验收标准**：
- [ ] 创建临时目录"temp"
- [ ] 将项目文件复制到临时目录
- [ ] 处理完成后将结果文件移动到项目目录
- [ ] 清理临时目录

### CMDB-008: 错误处理

**描述**：系统必须在各个阶段提供清晰的错误处理。

**验收标准**：
- [ ] 资源录入表不存在时，提示用户但继续执行
- [ ] 安全资源表不存在时，提示用户但继续执行
- [ ] Excel文件损坏时，记录错误并跳过该文件
- [ ] 所有错误必须记录到日志文件

## Delta Spec: Auto-Fill from PDF

### Changed Requirements

#### CMDB-002: Excel初始化（修改）

**变更内容**：
- **原行为**：A列单元格同时包含标签和值（如 `A1: ["需求人：", "张三"]`）
- **新行为**：A列包含标签，B列包含值（如 `A1: ["需求人："]`, `B1: ["张三"]`）
- **理由**：将标签和值分离，提高可读性

**验收标准（更新）**：
- [ ] 第1-6行填写项目基本信息：
  - A1: "需求人："，B1: 申请人姓名
  - A2: "需求方："，B2: 需求方名称
  - A3: "OA发文时间："，B3: OA发文日期
  - A4: "是否分批："，B4: 是否分批交付
  - A5: "主账号："，B5: 主账号
  - A6: "项目名称："，B6: 项目名称
  - A7: "新增子网信息："，B7: 子网信息
- [ ] 优先使用PDF提取的信息填充B列
- [ ] PDF提取失败时，使用用户手动输入的信息

#### CMDB-003: PDF信息自动提取（新增）

**描述**：在Excel初始化前，系统必须尝试从PDF中自动提取项目信息。

**实现方式**：
1. 调用 `pdf_extractor.ExtractFromPDF(root)` 获取 `*PdfInfo`
2. 如果成功，将提取的信息作为默认值传递给 `InputMessagesWithDefaults()`
3. 如果失败，记录 `Warn` 日志并调用原有的 `InputMessages()`

**验收标准**：
- [ ] PDF提取成功时，使用提取的信息
- [ ] PDF提取失败时，回退到手动输入
- [ ] 记录详细的日志信息

## Non-Functional Requirements

### 性能
- 整个流程应在 30 秒内完成（针对常规项目）
- PDF提取应在 5 秒内完成

### 可维护性
- 代码结构清晰，模块职责明确
- PDF提取逻辑独立于CMDB逻辑

### 兼容性
- 必须保持向后兼容
- PDF提取失败时，功能仍可正常使用
