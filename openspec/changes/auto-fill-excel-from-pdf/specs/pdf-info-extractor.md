# Spec: PDF Info Extractor

从集中流程管理系统的PDF文件中提取项目关键信息。

## REQUIREMENTS

### PDF-001: PDF文件定位
系统必须在用户输入目录的"1、订购评审纪要"子目录下自动查找PDF文件。
- 支持两种PDF命名模式：包含"集中流程管理系统"或匹配 `[A-Z]\d{3}`
- 目录不存在或文件不存在时返回错误

### PDF-002: PDF文本提取
系统必须使用 `tools/pdftotext.exe` 工具将PDF内容转换为文本。

### PDF-003: 申请人提取
使用正则 `申请人：\s*(\p{Han}+)` 提取申请人姓名。

### PDF-004: 需求方提取
使用正则 `所属独立业务X：\s*X_(.+)` 提取需求方，去除"X_"前缀。

### PDF-005: OA发文时间提取
使用正则从"公有云资源订购部署信息接收"创建时间中提取日期（`YYYY-MM-DD`格式）。

### PDF-006: 主账号提取
使用正则 `订购帐号：\s*(\w+)` 提取订购账号。

### PDF-007: 错误处理
各个阶段提供清晰的错误信息和日志。

### PDF-008: 接口设计
提供 `ExtractFromPDF(root string) (*PdfInfo, error)` 接口。
